> **Blogify API** is a RESTful backend service for a blogging platform.  
It provides secure user authentication and complete CRUD functionality for blog posts using modern web technologies.

---

## 📌 1. Project Description

Blogify API is a scalable and secure backend system built with **Node.js** and **Express.js**.  
It enables users to register, authenticate, and manage blog posts using JWT-based authentication and MongoDB Atlas for data storage.

---

## ✨ 2. Features

✅ User Registration & Login  
✅ JWT-Based Authentication  
✅ Secure Password Hashing  
✅ CRUD Operations for Blog Posts  
✅ RESTful API Architecture  
✅ MongoDB Atlas Integration  
✅ Environment-Based Configuration  
✅ Production-Ready Deployment
